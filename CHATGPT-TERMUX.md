# Puente Termux <-> GitHub <-> ChatGPT

Este repositorio es mi Termux.

- Todo lo que esta aqui debe ejecutarse en Termux en Android.
- Cuando ChatGPT haga cambios aqui, yo hare git pull en mi telefono para bajarlos.
- Cuando yo haga cambios en Termux, hare git push para subirlos.

Instruccion para ChatGPT: Trabaja directamente en este repo como si fuera mi Termux.
